# Student Portal 🎓

A responsive, cleanly designed academic portal dashboard built with semantic HTML5 and vanilla CSS3. Designed with a strict three-color palette, this portal provides student profile details, weekly class timetables, and a course enrollment form.

🔗 **Live Demo:** [https://y4sh1133.github.io/Student-portal/](https://y4sh1133.github.io/Student-portal/)

---

## ✨ Features

- **Student Profile Dashboard:** Structured table displaying student details, major, and academic status badges.
- **Weekly Schedule:** Complete Monday-to-Friday schedule table for tracking daily classes, labs, and workshops.
- **Course Registration Form:** Interactive registration interface supporting:
  - Input validation for personal contact information
  - Course selection via dynamic dropdown
  - Radio toggles for delivery preference (Online vs. Offline)
  - Multi-select checkboxes for prerequisite technical skills
- **Design System:** Custom 3-color palette utilizing Pure White (`#ffffff`), Midnight Navy (`#00171f`), and Prussian Blue (`#003459`).
- **Responsive Layout:** Optimized with custom media queries for mobile, tablet, and desktop viewports.

---

## 🛠️ Built With

- **HTML5:** Semantic document structure (`<header>`, `<main>`, `<nav>`, `<table>`, `<form>`)
- **CSS3:** Custom CSS variables, Flexbox layouts, smooth hover transitions, and mobile breakpoints
